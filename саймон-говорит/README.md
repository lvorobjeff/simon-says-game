# 🎮 Саймон Говорит (Simon Says)

A fun, interactive memory game built with vanilla HTML, CSS, and JavaScript. Test your memory by repeating increasingly complex color sequences!

## Features

- 🎨 **Colorful UI** - Beautiful gradient design with smooth animations
- 🔊 **Sound Effects** - Each color has a unique tone using Web Audio API
- ⚡ **Difficulty Levels** - Choose between Easy, Normal, and Hard modes
- 📊 **Score Tracking** - Monitor your level and score in real-time
- 📱 **Responsive Design** - Works seamlessly on mobile and desktop

## How to Play

1. Click **"Старт"** (Start) to begin
2. Watch the color sequence Simon displays
3. Click the colors in the **exact same order**
4. Each round, the sequence gets one color longer
5. How many levels can you reach before making a mistake?

## Difficulty Modes

- 🟢 **Легко (Easy)** - 800ms display time, 1200ms wait
- 🟡 **Нормально (Normal)** - 600ms display time, 1000ms wait  
- 🔴 **Сложно (Hard)** - 400ms display time, 600ms wait

## Getting Started

Simply open `index.html` in your web browser and start playing!

## Technical Details

- **No dependencies** - Pure vanilla JavaScript
- **Web Audio API** - Creates game tones dynamically
- **CSS Grid & Flexbox** - Modern responsive layout
- **ES6 JavaScript** - Clean, maintainable code

Enjoy the game! 🎮
