## 🇷🇺 Русский

### Саймон Говорит

Веселая интерактивная игра на память, созданная на чистом HTML, CSS и JavaScript. Проверьте свою память, повторяя все более сложные последовательности цветов!

### Особенности

- 🎨 **Красивый интерфейс** - Изящный дизайн с градиентами и плавными анимациями
- 🔊 **Звуковые эффекты** - Каждый цвет имеет уникальный звук благодаря Web Audio API
- ⚡ **Уровни сложности** - Выбирайте между режимами Легко, Нормально и Сложно
- 📊 **Отслеживание очков** - Видите уровень и счет в реальном времени
- 📱 **Адаптивный дизайн** - Работает на мобильных и десктопных устройствах

### Как играть

1. Нажмите **"Старт"** чтобы начать
2. Смотрите последовательность цветов, которую показывает Саймон
3. Нажимайте цвета **в точно таком же порядке**
4. Каждый раунд последовательность становится на один цвет длиннее
5. Сколько уровней вы сможете пройти без ошибок?

### Уровни сложности

- 🟢 **Легко** - 800ms показ, 1200ms ожидание
- 🟡 **Нормально** - 600ms показ, 1000ms ожидание
- 🔴 **Сложно** - 400ms показ, 600ms ожидание

### Начало работы

Просто откройте `index.html` в веб-браузере и начните играть!

### Технические детали

- **Нет зависимостей** - Чистый ванильный JavaScript
- **Web Audio API** - Динамическое создание звуков игры
- **CSS Grid & Flexbox** - Современная адаптивная верстка
- **ES6 JavaScript** - Чистый, поддерживаемый код

Наслаждайтесь игрой! 🎮

## 🇬🇧 English

### Simon Says

A fun, interactive memory game built with vanilla HTML, CSS, and JavaScript. Test your memory by repeating increasingly complex color sequences!

### Features

- 🎨 **Colorful UI** - Beautiful gradient design with smooth animations
- 🔊 **Sound Effects** - Each color has a unique tone using Web Audio API
- ⚡ **Difficulty Levels** - Choose between Easy, Normal, and Hard modes
- 📊 **Score Tracking** - Monitor your level and score in real-time
- 📱 **Responsive Design** - Works seamlessly on mobile and desktop

### How to Play

1. Click **"Старт"** (Start) to begin
2. Watch the color sequence Simon displays
3. Click the colors in the **exact same order**
4. Each round, the sequence gets one color longer
5. How many levels can you reach before making a mistake?

### Difficulty Modes

- 🟢 **Easy** - 800ms display time, 1200ms wait
- 🟡 **Normal** - 600ms display time, 1000ms wait
- 🔴 **Hard** - 400ms display time, 600ms wait

### Getting Started

Simply open `index.html` in your web browser and start playing!

### Technical Details

- **No dependencies** - Pure vanilla JavaScript
- **Web Audio API** - Creates game tones dynamically
- **CSS Grid & Flexbox** - Modern responsive layout
- **ES6 JavaScript** - Clean, maintainable code

Enjoy the game! 🎮
